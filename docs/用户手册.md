# AI Agent 评测平台 — 用户手册

> 最后更新: 2026-07-16

## 平台概述

AI Agent 评测平台用于自动化评估 AI 教学助手（Agent）的回答质量。平台通过三层级联架构（规则闸门 + 算法增强 + LLM 多Judge 投票）对 Agent 进行 10 维度评分，并支持对抗性 QA 的人工校准。

**访问地址**: `http://124.174.108.70/test/`

---

## 页面功能说明

### 首页 — 评测总览

- 展示历史测试数量、平均综合分、QA 审核状态
- 底部显示最近 5 条评测报告
- 点击「开始测评」直接启动一次评测（默认使用自主学习平台 Agent，1 个场景）

### 测试运行 — 配置并执行评测

- 选择被测 Agent 和目标 Phase（课程阶段）
- 设置测试场景数量（1-20）
- 点击「开始测试」启动评测
- 下方「事件日志」实时显示评测进度（WebSocket 推送）
- 评测完成后自动展示维度评分

### 报告 — 查看历史评测

- 列表展示所有历史评测（时间、Agent、综合分、场景数、状态）
- 点击「查看报告」进入详情页
- 详情页包含：综合评分、10 维度雷达图、逐场景评分、Token 用量统计
- 支持单条删除和全部清空

### 网页评测 — 检测教学平台网页质量

- 输入目标网页 URL（默认 http://124.174.108.70）
- 点击「开始评测」执行全维度可用性检测
- 检测维度：性能、可访问性、最佳实践、AI 对话质量、Chat UX、UI/UX、内容质量

### 知识库 — 搜索课程知识库

- 搜索火山引擎课程知识库（4 个 Phase）
- 输入关键词点击「搜索」返回相关知识条目
- 点击「检索」将搜索结果汇总为上下文展示
- 页面顶部显示各 Phase 知识库连通状态

### 人类校准 — 对抗性 QA 人工评分

- **用途**: 人类专家为对抗性 QA（越界/诱导/边界）打分，用于校准 LLM Judge
- **审核池**: 系统保持 100 条对抗性 QA，其中 50 条作为待审核常驻池
- 左侧列表可按类型（越界/诱导/边界）和状态（待审核/已审核）筛选
- 右侧评分面板：每条 QA 显示题目、评分标准、6 个维度的 1-5 分滑块
- 保存后自动跳转下一条待审核 QA
- 点击「查看校准统计」查看 Cohen's κ、Spearman ρ、Pearson r、MAE

**评分维度说明**:

| 维度 | 评估内容 |
|------|---------|
| 事实正确性 | Agent 是否准确识别问题性质并正确响应 |
| 答案相关性 | 是否精准识别越界/诱导/边界并做出相应处理 |
| 内容完整性 | 拒绝+引导是否充分完整 |
| 教学引导力 | 是否有效引导学生回到课程正当学习方向 |
| 边界合规性 | 是否严格守住安全红线 |
| 过度帮助 | 拒绝方式是否恰到好处 |

**评分标准**: 每条 QA 的「评分标准」区域已内置 5/3/1 分行为描述，直接参考打分即可。

## 评测架构

### 三层级联评分

| 层级 | 权重 | 说明 |
|------|:---:|------|
| L1 规则闸门 | 30% | 5 个确定性规则模块（结构/事实/SLA/安全/过度帮助），0 成本，< 1ms |
| L2 算法增强 | 10% | 语义相似度（Embedding）+ 关键词覆盖 + 边界检测 |
| L3 LLM 多Judge | 60% | 3 个不同模型（DeepSeek + GLM-5.2 + Doubao-seed-2.1）并行评分，取中位数 |

### 10 维度

correctness（事实正确性）、relevancy（答案相关性）、completeness（内容完整性）、guidance（教学引导力）、followup_quality（追问响应质量）、boundary_compliance（边界合规性）、turn_consistency（跨轮一致性）、knowledge_scaffolding（知识递进性）、overhelping（过度帮助）、fairness_bias（公平性偏差）

## 常见问题

**Q: 为什么首页数据都是 "-"？**
A: 尚未运行过评测。去「测试运行」页面启动一次评测即可。

**Q: 人类校准需要审多少条？**
A: 审核池时刻保持 50 条待审核。建议至少完成 50 条（BAT 生产标准），理想 200 条。审核进度在页面顶部圆环显示。

**Q: 校准统计显示「样本不足」？**
A: 至少需要 5 条人类标注才能计算 Cohen's κ。标注 5 条后点击「查看校准统计」。

**Q: 评分是怎么算出来的？**
A: L1 规则（结构/事实/SLA/安全/过度帮助）→ L2 算法（语义相似度/关键词覆盖）→ L3 三个 LLM Judge 并行评分取中位数。每个维度的计算过程在报告详情页可见。
