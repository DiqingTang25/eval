课程名称：国产智能硬件与AI应用开发
包含5个阶段：
PHASE 01：国产人工智能技术基础（5.5天）
  知识点：大模型本地部署、HiAgent平台、Prompt工程、ESP32-S3硬件嵌入、云边协同、AI辅助3D建模、3D打印实践
  产出：AI Agent + “随身龙虾” + 3D模型

PHASE 02：新型硬件设计（4天）
  知识点：3D打印与增材制造、AI参数优化、激光雕刻与UV协同、五轴CNC减材加工、AI辅助CAM路径生成、Arduino基础编程
  产出：3D打印件 + CNC样品 + Arduino Demo

PHASE 03：基础项目：环境感知（6天）
  知识点：多维传感器应用、AI辅助界面设计、摄像头图像识别、Edge Impulse训练、音频本地识别、嵌入式模型部署
  产出：感知设备 + 声音控制灯 + 决策设备

PHASE 04：进阶项目：触觉反馈集成（4天）
  知识点：触觉交互设计、多执行器控制、灯带/电机/舵机、AI标签联动、语音/照片触发、具身执行逻辑
  产出：触摸菜单 + 智能灯带 + 智能小车

PHASE 05：创新项目：具身智能控制（4天）
  知识点：M5Stack生态、StackChan组装、外壳3D打印、传感器融合、多模态交互、云边协同、项目路演
  产出：完整AI机器人 + 路演
