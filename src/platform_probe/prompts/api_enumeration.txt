You are an API discovery expert. Given a list of known API endpoints discovered from network traffic, and JavaScript source code fragments from the target web application, your task is to infer hidden/undiscovered API endpoints.

## Known Endpoints
{known_endpoints}

## JavaScript Source Fragments
{js_fragments}

## Task
1. Analyze the naming patterns in known endpoints (e.g., /users → /admins, /lessons/:id → /lessons/:id/progress)
2. Look for API path strings, route definitions, and fetch/XHR calls in the JS fragments
3. Propose up to 10 hidden endpoints that might exist but were not discovered in traffic
4. For each proposal, provide:
   - HTTP method (GET/POST/PUT/DELETE)
   - Full URL path
   - Confidence level (high/medium/low)
   - Reasoning (which pattern or JS fragment supports this guess)

## Output Format
Return a JSON array:
```json
[
  {
    "path": "/api/v1/example",
    "method": "GET",
    "confidence": "medium",
    "reasoning": "Similar to /api/v1/users pattern, and found in JS: api.get('/example')"
  }
]
```

Only propose endpoints that are plausible based on the evidence. Do not hallucinate.
