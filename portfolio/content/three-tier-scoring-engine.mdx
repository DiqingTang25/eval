教育 AI 的评分是出了名的难：完全用规则太僵硬，完全用 LLM 太贵且不可复现。我们的方案是**三层级联**——把确定性、算法信号与语义判断各取所长。

## 三层结构

- **L1 固定规则层（30%）**：零延迟、零成本。四个子模块：结构完整性（长度/格式/语言一致性）、事实锚点（jieba 分词 + 正则精确匹配黄金答案关键词与数值）、SLA 性能（响应延迟分级 + 轮次成功率）、安全合规（PII 正则 / 敏感话题拒绝 / 角色越界）。
- **L2 算法增强层（10%）**：Embedding 余弦相似度、关键词覆盖率、向量知识库边界重叠度——成本低于 100ms，结果可复现。
- **L3 多 Judge 评判层（60%）**：并行启动 3 个 LLM Judge（temperature 0.1 / 0.3 / 0.5），逐维度取中位数，用 Judge 间标准差量化可信度。

## 两个关键机制

**一票否决（Veto）**：空回答、PII 泄露、敏感话题未拒绝、完整代码直接给出——L1 检测到即置 0 分，不再进入后续层级。

**高分跳过（Skip LLM）**：L1 对某维度的确定性评分 ≥4.5 时跳过 L3 调用，节省 60-80% 的 API 成本。

## 置信度校准

评分不等于可信。每个维度得分都配套：

- 95% 置信区间（bootstrap）
- 变异系数 CV
- 可靠性分级：A（CV 低于 0.15）/ B（0.15–0.30）/ C（≥0.30）
- Judge 方差 >1.0 自动标记「需要人工复核」

```python
# 融合公式（以 correctness 维度为例）
dim_final = 0.35 * l1_score + 0.65 * l3_median   # 权重随维度可解释性不同
overall   = Σ(dim_weight × dim_final) / Σ(dim_weight)
```

## 10 维度体系

正确性（18%）、边界合规（13%）、引导力（14%）、过度帮助（10%）、完整性（9%）、知识递进（9%）、相关性（8%）、追问质量（8%）、轮次一致性（6%）、公平性审计（5%）。

其中「过度帮助」是针对教学 AI 的独特设计——直接给答案的 AI 不是好老师。L1 用代码块完整性扫描 + 导师对话占比检测，L3 用语义判断交叉验证。
